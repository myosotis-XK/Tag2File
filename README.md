# Tag2File 使用指南

Tag2File 是一个强大的标签式文件管理工具，帮助你通过标签快速组织、搜索和访问文件。它同时提供**桌面客户端**和**Web界面**，满足不同场景的使用需求。

---

## 🚀 快速上手

### 启动应用程序

直接运行 `Tag2File.exe` 即可启动程序。

您可以在同一局域网内的其他设备上通过浏览器访问具备基本查询功能网页：
* 点击开始菜单中的“web端入口”，可以看到网址和二维码，输入网址或扫描二维码即可在手机上打开Web界面。

---

## ✨ 核心功能详解

### 1. 标签表达式搜索

Tag2File 最强大的功能是支持复杂的标签表达式搜索，让你能够精确找到所需文件。
标签表达式与数学的集合运算一致，支持以下操作符：

| 操作符 | 含义 | 示例 | 描述 |
| :---: | :---: | :--- | :--- |
| `∩` | 交集 | `风景 & 日出` | 查找**同时包含**"风景"和"日出"标签的文件。 |
| `∪` | 并集 | `风景 ∪ 城市` | 查找**包含任一**标签的文件。 |
| `'` | 补集 | `低质量'` | 查找**不包含**"低质量"标签的文件。 |
| `(` 和 `)` | 运算顺序 | `(风景 ∪ 城市) & 高质量` | 查找包含"风景"或"城市"，且同时包含"高质量"标签的文件。 |

### 2. 标签管理 (桌面客户端)

* **管理标签**：点击 "**管理标签**" 按钮，进入标签编辑界面。
* **标签库**：从菜单栏的 "**开始**" → "**标签库**" 进入完整的标签库管理界面。

### 3. 类别管理 (桌面客户端)

* **管理类别**：点击 "**管理类别**" 按钮，进入类别编辑界面。
* **标签类别**：你可以为标签定义类别，以实现更清晰的标签组织。
* **特殊类别**：你可以将类别设置为**特殊类别**，以实现常驻的过滤功能，可以省去取补集的操作。

### 4. 文件相关功能

* **显示** 支持**缩略图**浏览模式，可以在**小**、**中**、**大**三种缩略图尺寸切换之间切换
* **排序** 支持按**文件名**、**文件大小**、**创建时间**、**随机**排序
* **文件操作** 支持**打开**、**复制**、**剪切**、**重命名**、**删除**文件
>     注意：标签是通过文件路径来指向文件的，只有通过应用内的文件操作才能保证标签的正确更新。

## ⚙️ 配置说明

### 配置文件

默认情况下，配置文件存储在以下位置：
* `Tag2File/config/config.ini`  

你可以在配置文件中修改应用的各种参数

### 标签库存储位置

默认情况下，标签库数据存储在以下位置：
* `Tag2File/data/tagbase/`

### 缩略图缓存位置

默认情况下，缩略图缓存存储在以下位置：
* `Tag2File/data/cache/image`

## 💡 高级技巧

1.  **高效使用标签表达式**
    * 善用括号组合复杂条件。
    * 记住常用的标签组合，提高搜索效率。
    * 结合特殊类别过滤，可以更快速地定位文件。
2.  **性能优化**
    * 尽量不要使查询结果包含过多文件，避免应用卡顿。
    * 使用固态硬盘可以大幅提升缩略图加载速度。

## 关于打包
在根目录下执行以下命令打包：
```bash
pyinstaller --name Tag2File --windowed --onefile --icon=data/icon/app/favicon.ico main.py
```
打包完成后将dist文件夹下的Tag2File.exe应用程序移动根目录下，然后运行即可。
