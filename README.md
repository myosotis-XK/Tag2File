# Tag2File 使用指南

Tag2File 是一个强大的标签式文件管理工具，帮助你通过标签快速组织、搜索和访问文件。它同时提供**桌面客户端**和**Web界面**，满足不同场景的使用需求。

---

## 🚀 快速上手

### 启动应用程序

直接运行 `main.py` 文件即可启动程序。

启动后，程序会同时启动以下几个核心组件：
* **PyQt5 桌面界面**
* **Flask Web 服务器**（默认端口：`10252`）
* **缓存管理进程**

### 访问方式

* **桌面客户端**：程序启动后自动打开
* **Web浏览器**：在浏览器中访问 `http://localhost:10252` 或 `http://你的IP:10252`

---

## ✨ 核心功能详解

### 1. 标签表达式搜索

Tag2File 最强大的功能是支持复杂的标签表达式搜索，让你能够精确找到所需文件。

| 操作符 | 含义 | 示例 | 描述 |
| :---: | :---: | :--- | :--- |
| `&` | 逻辑与 | `风景 & 日出` | 查找**同时包含**"风景"和"日出"标签的文件。 |
| `∪` | 逻辑或 | `风景 ∪ 城市` | 查找**包含任一**标签的文件。 |
| `'` | 逻辑非 | `'不重要` | 查找**不包含**"不重要"标签的文件。 |
| `(` 和 `)` | 组合 | `(风景 ∪ 城市) & 高质量` | 查找包含"风景"或"城市"，且同时包含"高质量"标签的文件。 |

### 2. 标签管理 (桌面客户端)

* **管理标签**：点击 "**管理标签**" 按钮，进入标签编辑界面。
* **管理类别**：点击 "**管理类别**" 按钮，可创建和编辑标签类别。
* **标签库**：从菜单栏的 "**开始**" → "**标签库**" 进入完整的标签库管理界面。

### 3. 文件浏览

| 客户端 | 模式/功能 | 描述 |
| :---: | :---: | :--- |
| **桌面客户端** | 浏览模式 | 支持**列表**和**缩略图**两种浏览模式。 |
| **Web界面** | 缩略图尺寸 | 支持**小**、**中**、**大**三种缩略图尺寸切换。 |
| **通用** | 文件操作 | 点击文件或缩略图可**直接打开**对应文件。 |
| **Web界面** | 性能优化 | 使用**虚拟滚动**技术，流畅浏览大量文件。 |

### 4. 特殊过滤 (Web界面)

Web界面提供了文件类型过滤功能，通过勾选/取消勾选可快速筛选：
* **图片**
* **视频**
* **音频**
* **其他**

## ⚙️ 配置说明

### Web服务地址配置

如果你的服务器IP或端口发生变化，需要修改 Web 界面中的服务地址配置。

* **文件路径**：`web_app/tag2file.html`
* **大致行号**：第 474 行左右
* **配置项**：
    ```javascript
    const API_BASE_URL = '[http://192.168.0.102:10252](http://192.168.0.102:10252)'; // 修改此处的IP地址和端口号
    ```

### 标签库存储位置

默认情况下，标签库数据存储在以下位置：
* `Tag2File/data/tagbase/`

你可以在 `DictManage.py` 中的配置部分修改此路径。

## 💡 高级技巧

1.  **高效使用标签表达式**
    * 善用括号组合复杂条件。
    * 记住常用的标签组合，提高搜索效率。
    * 结合文件类型过滤，可以更快速地定位文件。
2.  **多设备访问**
    * Web界面设计为响应式布局，可在手机、平板和电脑上良好使用。
    * 只需在其他设备上输入运行 Tag2File 的电脑 **IP 地址和端口号**即可访问。
3.  **性能优化**
    * 对于大量文件，建议使用**中**或**小尺寸**的缩略图视图。
    * Web界面采用**虚拟滚动技术**，即使有成千上万的文件也能流畅浏览。

## 🛠️ 故障排除

| 问题 | 检查项 |
| :--- | :--- |
| **无法连接到服务器** | 1. 确认 Tag2File 程序正在运行。|
| | 2. 检查防火墙设置是否阻止了端口 `10252` 的访问。|
| | 3. 确认 `API_BASE_URL` 配置正确，特别是 IP 地址部分。|
| **搜索结果为空** | 1. 检查标签表达式是否正确。|
| | 2. 确认是否有文件匹配当前的标签和文件类型过滤条件。|
| | 3. 确保文件已经被正确标记。|

## ✅ 提示与建议

* 为了获得最佳体验，建议为文件添加**多个相关标签**。
* 合理组织**标签类别**，让标签体系更加清晰。
* **定期备份**你的标签库数据，避免意外丢失。
* 在使用Web界面时，确保设备在**同一局域网内**以获得最佳性能。

通过 Tag2File，你可以更高效地组织和访问大量文件，特别适合照片、文档和媒体文件的管理。




## 🚀 运行指南 (Run Instructions)

本项目由一个集成 Flask 后端的 Qt 桌面应用 (`Tag2File.exe`) 和一个Web 简化前端界面 (`tag2file.html`) 组成。`Tag2File.exe` 在启动时会同时启动后端服务。

### 步骤 1: 启动应用

1.  **运行主程序：** 双击执行 Tag2File.exe。 (如果没有Tag2File.exe文件或修改过源码，请自行打包)
>     该程序会启动一个 Qt 桌面界面，并在后台同时启动 Flask 后端服务。

### 步骤 2: 配置 Web 应用（可选，如果想要在其他设备上访问Web界面）

由于前端和后端需要在局域网内通信，您需要手动修改前端 HTML 文件中的 IP 地址。

1.  **检查端口：** 确保后端服务成功启动，并在默认端口 10252 监听。
2.  **获取 IP 地址 (关键):** * 在运行 `Tag2File.exe` 的这台电脑上，打开命令提示符 (CMD) 或 PowerShell。
    * 输入命令 `ipconfig`，找到你的 Wi-Fi 或以太网适配器下的 **IPv4 地址**（例如：`192.168.1.5`）。
    * **记住这个 IP 地址，这是其他设备用来访问你的服务的地址。**

> ⚠️ **注意防火墙：** 如果您是首次运行，Windows 防火墙可能会阻止连接。请确保您允许应用程序访问私有网络。
3.  用任意文本编辑器（如 VS Code, Notepad++）打开 `tag2file.html` 文件。
4.  找到以下代码行：
    ```javascript
    // 后端服务地址 - 请替换为您的Windows电脑IP
    const API_BASE_URL = '[http://192.168.0.102:10252](http://192.168.0.102:10252)'; 
    ```
5.  将 `192.168.0.102` **替换**为您在 **步骤 1** 中获取的 IPv4 地址。
    * **示例：** 如果 IP 是 `192.168.1.5`，则修改为 `const API_BASE_URL = 'http://192.168.1.5:10252';`


### 步骤 3: 使用应用
完成配置后，您可以通过以下两种方式使用应用：

1. 使用原生 Qt 桌面应用：

    * 直接在运行 Tag2File.exe 的电脑上操作其 Qt 界面。

2. 使用 Web 简化前端：

    * 在同一台电脑上访问： 用浏览器打开您修改后的 tag2file.html 文件。

    * 在局域网内其他设备上访问 (如手机)： 在浏览器中输入对应的局域网地址，格式为 http://[您的电脑IP地址]:[端口]。

        💡 示例： 如果您的电脑 IP 地址是 192.168.1.5，端口是 10252，则输入： http://192.168.1.5:10252/

## 关于打包
在根目录下执行以下命令打包：
```bash
PyInstaller --name Tag2File --windowed --onefile main.py
```
打包完成后将dist文件夹下的Tag2File.exe应用程序移动根目录下，然后运行即可。
